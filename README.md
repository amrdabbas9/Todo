## Overview

### The challenge

Users should be able to:

- View the optimal layout for the app depending on their device's screen size
- See hover states for all interactive elements on the page
- Add new todos to the list
- Mark todos as complete
- Delete todos from the list
- Filter by all/active/complete todos
- Clear all completed todos
- Toggle light and dark mode
- **Bonus**: Drag and drop to reorder items on the list

### What I learned

This is my first challenge with Frontend Mentor. It was very useful, and I've learned so much throughout the journey of making this project. It is not a hard challenge, but creating a project from scratch with a beautiful design and improving it step by step was challenging at first. Initially, I did the project using CSS, but after writing so much of it, I searched for a faster way to write CSS code, and that's when I found Tailwind CSS. It is really a game changer. Because I am good at CSS, I learned and started using Tailwind CSS so fast. The hardest part of the project was adding the 'drag and drop' feature to order tasks. I did it first using JavaScript, and it worked just fine. But after a couple of weeks, while I was still improving my React skills, I started learning the Framer Motion library. It is so easy to use, and I ended up replacing so much of the JavaScript code with just a couple of lines to do the same job. It was a fun project to do, and I will continue improving it as I progress with my learning journey.
